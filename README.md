# Cloud Automate Website

A marketing website for Cloud Automate, designed with a modern security and automation brand look inspired by the reference design.

## Open locally

From this folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Highlights

- Hero section with the key message: "Experience It: Pay Only for Results"
- About, services, process, portfolio, testimonials, team, FAQ, and contact sections
- Responsive layout for desktop and mobile
- Contact form, private admin section, message logging, and saved history
- Password-protected team management with photo upload and local browser storage
